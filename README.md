# Эмулятор командной оболочки UNIX-подобной ОС с виртуальной файловой системой 

Консольный эмулятор shell, повторяющий ключевые команды UNIX-подобных ОС
(`ls`, `cd`, `cat`, `touch`, `mv` и др.). Все операции с файловой системой
выполняются **в памяти** над виртуальной ФС (VFS), загружаемой из
ZIP-архива. Исходный архив не модифицируется; состояние можно сохранить
командой `vfs-save`.

Реализовано на Python 3.9+ (стандартная библиотека, без внешних зависимостей).

---


### Этап 1 — REPL
- Консольный интерфейс с приглашением вида `username@hostname:/path$`,
  построенным на основе реальных данных ОС (`getpass`, `socket`).
- Простой парсер ввода (разделение на команду и аргументы через `shlex`).
- Обработка ошибок: неизвестная команда, неверные аргументы, отсутствие файлов.
- Команда `exit` для выхода.

### Этап 2 — Конфигурация
- Параметры командной строки:
  - `--vfs <путь>` — путь к ZIP-архиву VFS;
  - `--startup <путь>` — путь к стартовому скрипту;
  - `--debug` — отладочный вывод параметров при запуске.
- Стартовые скрипты выполняются последовательно, ошибочные строки пропускаются;
  диалог имитируется отображением приглашения и введённой команды.

### Этап 3 — Виртуальная файловая система
- Загрузка VFS из ZIP-архива, полностью в память (без распаковки на диск).
- Поддержка бинарных данных (base64 при выводе через `cat`).
- Обработка ошибок: файл не найден, неверный формат ZIP.
- Команда `vfs-save <путь>` — сохранение состояния VFS в ZIP на диск.
- Команда `vfs-info` — статистика по загруженной VFS.

### Этап 4 — Основные команды
- `ls` (с флагами `-a`, `-l`), `cd`, `pwd`, `cat`, `find`, `tree`.
- `uname` (`-a`), `du`, `rev`.

### Этап 5 — Дополнительные команды
- `touch`, `mv`, `rm` (с флагами `-r`, `-f`) — изменения только в памяти.

### 1. Тестовые VFS-архивы

```bash
python scripts/create_vfs_archives.py
```

При успехе в папке `vfs_archives/` появятся три архива:
`minimal_vfs.zip`, `medium_vfs.zip`, `complex_vfs.zip`.

### 2. Запустить эмулятор

**Интерактивный режим без VFS** (демонстрация REPL и обработки ошибок):

```bash
python shell_emulator.py
```

```
user@host:~$ ls
ls: VFS не загружена
user@host:~$ unknowncmd
Ошибка: команда не найдена: unknowncmd
user@host:~$ exit
Выход...
```

**Интерактивный режим с VFS:**

```bash
python shell_emulator.py --vfs vfs_archives/complex_vfs.zip --debug
```

**С выполнением стартового скрипта:**

```bash
python shell_emulator.py \
    --vfs vfs_archives/complex_vfs.zip \
    --startup test_scripts/stage3_vfs.sh \
    --debug
```

## Параметры командной строки

| Параметр | Описание |
|---|---|
| `--vfs PATH` | Путь к ZIP-архиву VFS. Если не указан, команды, работающие с VFS, сообщают об ошибке. |
| `--startup PATH` | Путь к стартовому скрипту. Строки выполняются последовательно, ошибочные пропускаются. |
| `--debug` | Отладочный вывод всех параметров запуска (для этапа 2). |

## Реализованные команды

### Навигация и чтение

| Команда | Описание | Пример |
|---|---|---|
| `ls [-a] [-l] [PATH]` | Список содержимого каталога | `ls -la /home/user` |
| `cd [PATH]` | Смена текущего каталога | `cd /home/user` |
| `pwd` | Текущий каталог | `pwd` |
| `cat FILE...` | Вывод содержимого файла (бинарные — в base64) | `cat notes.txt` |
| `find PATTERN` | Поиск по имени (с поддержкой `*`/`?`) | `find *.txt` |
| `tree` | Дерево от текущего каталога | `tree` |

### Системная информация

| Команда | Описание | Пример |
|---|---|---|
| `uname [-a]` | Информация о системе | `uname -a` |
| `du [PATH]` | Размер каталога/файла в байтах | `du .` |

### Текстовые операции

| Команда | Описание | Пример |
|---|---|---|
| `rev ARG` | Переворот строки или строк файла | `rev report.txt` |

### Изменение VFS (только в памяти)

| Команда | Описание | Пример |
|---|---|---|
| `touch FILE...` | Создать файл или обновить mtime | `touch new.txt` |
| `mv SRC DST` | Перемещение/переименование | `mv a.txt b.txt` |
| `rm [-r] [-f] PATH...` | Удаление файла/каталога | `rm -rf old_dir` |

### Работа с VFS

| Команда | Описание | Пример |
|---|---|---|
| `vfs-save PATH` | Сохранить текущее состояние VFS в ZIP | `vfs-save my_vfs.zip` |
| `vfs-info` | Статистика: файлов, каталогов, общий размер | `vfs-info` |

### Управление сессией

| Команда | Описание |
|---|---|
| `exit` | Выход из эмулятора |

### Обработка ошибок

Эмулятор корректно сообщает о проблемах, не завершаясь аварийно:

```
devil@host:/$ cd nonexistent
cd: nonexistent: Нет такого файла или каталога
devil@host:/$ cat missing.txt
cat: missing.txt: Нет такого файла или каталога
devil@host:/$ vfs-save /nonexistent/dir/x.zip
vfs-save: каталог не существует: C:\nonexistent\dir
devil@host:/$ foobar
Ошибка: команда не найдена: foobar
```
